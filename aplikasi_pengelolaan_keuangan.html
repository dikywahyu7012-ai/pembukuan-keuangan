Integrasi Google Sheets API / Apps Script

Anda dapat menghubungkan web ini secara langsung ke Google Spreadsheet milik Anda menggunakan Google Apps Script Web App URL.

Panduan Singkat Setup Google Sheets:
  1. Buka Google Sheets baru, klik menu Extensions > Apps Script.
  2. Salin & tempel kode skrip penampung (Apps Script) ke editor Google.
  3. Klik Deploy > New Deployment > Web App (Set Who has access: Anyone).
  4. Tempelkan URL Web App yang dihasilkan ke kolom di atas lalu simpan.
